# antep — Site portfolio d'Audrey Ntep

Portfolio single-file (HTML/CSS/JS), bilingue FR/EN, aux couleurs de la marque **antep**.

## Contenu
- `index.html` — site complet, autonome (aucune dépendance à installer). Logo et favicon encodés en base64.

## Déploiement
Site 100 % statique : déployable tel quel sur **Vercel**, **Netlify**, **GitHub Pages** ou tout hébergeur statique.
Aucune étape de build : il suffit de servir `index.html`.

## Stack mise en avant
Python · TypeScript · Solidity · FastAPI · Docker · IA (RAG, Computer Vision, agents) · Web3 (EVM, ICP, XRPL)
