De la donnée au code, jusqu'au Web3

J'ai commencé par les chiffres — SQL, dashboards, analyse — avec l'envie de transformer la donnée en décisions utiles. Puis j'ai découvert le code : Python, JavaScript, APIs, automatisation. Un développeur ne construit pas seulement des applications, il construit des solutions à des problèmes réels.

Ensuite est venue l'IA — prédire, automatiser, générer, optimiser. Puis le Web3 : décentralisation, smart contracts, transparence des échanges. Aujourd'hui je construis un écosystème cohérent où la data alimente l'IA, le code relie les systèmes, et le Web3 redéfinit la propriété numérique.

Mon approche : code sécurisé par défaut, tests automatisés, déploiement conteneurisé, livraison orientée résultats mesurables. Avant le développement, plus de 10 ans en gestion, comptabilité et entrepreneuriat — une vraie rigueur sur les processus métier et les enjeux business.
